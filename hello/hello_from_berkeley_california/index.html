I've lusted after a SuperDuke for some years; finally succumbed when I found a clean 2007 with only 1000 miles.

I've had it since July, it's pretty box-stock so far, though I have had the suspension set up by Dave Moss at Catalyst Reaction. I understand that I can free up some ponies using farkles named after dogs and arachnids, but for now I've chosen to put my money into fuel and tyres.

What a great machine. I really enjoy naked streetfighters, and this one has so far lived up to my expectations. I've taken a bunch of day rides on the local back roads, and finally got in a 900 mile weekend. I'm not much of a Forum bunny, but will post a ride story about the weekend ride as soon as I can.

-- Mark

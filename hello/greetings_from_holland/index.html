Hi!

I've been a member for a while but I figure let's introduce myself and contribute (and ask) some more around here.
Name is Sebastian and I'm from the Netherlands (The Hague to be specific).
Since june last year I am in possession of a 2010 Superduke R which I already love by now

I rode it last year like I bought it and figured I would put some energy in it this winter so up until now I've done;
- Wrapped the exhaust
- Different steering bar (Contour Henry/Reed bend)
- Checked the valve clearance
- Replaced spark plugs
- Changed the oil/screens/filter
- Dismounted the SAS
- Removed second throttle plates/flies
- Mounted RC8 velocity stacks
- Removed the crankcase breather from the airbox to a separate filter
- Removed the stock fuel filter from the fuel pump

And currently I am in the proces of;
- Putting in a in-line fuel filter between tank and TB's
- Mounting an ITG airfilter

I got a lot of helpful info from this forum as well as the current map I'm running (akra smoothened).
The 28th it's going on the dyno to see how it runs, until then I'm looking around to find a better suitable map for my current set-up but it's not that easy.

In short; Hi, see you around!

Been looking for a frame stand to remove my shock.
Wasn't gonna spend £100 on an abba type to use once or twice so here's a cheap alternative.

Pair of car axle stands (£15 if u ain't got a set laying about)
And two 3/4" extension bars.

Put bike on paddock stand and set this up either side.



Simple. Cheap. Adjustable. Job done

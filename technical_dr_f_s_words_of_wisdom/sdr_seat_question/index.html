There is a difference between the '05/'06 and '07 SD R seat kit. It's the internal plastic tray where all the fuses and tool kit sit, it's different between the two models but I believe that's the only difference. As for the exhaust, there is no problem, the kit doesn't require any mods to the exhaust so you can run with the stock setup or aftermarket cans with no problems. The seat looks higher, but in fact the seat pad is actually lower, probably because it's only feels like it's 2mm thick

'05/'06 SD R seat kit part # 61108200000
'07 SD R seat kit part # 61108200100

You could try these guys http://www.bikersjersey.com/ They ship worldwide and don't charge VAT which is a big saving. Try emailing them, but I've not always had a response, best to phone. Don't be put off by them not listing on their website that they are'nt KTM dealers, because they are.

Hi all,

I've only just been introduced to the wild world of the SD. Just got a runout Orange 07. Loving it but after only 200kms the Neutral indicator is always on. At first I suspected that the problem could be the signal from the gearbox, so I tried to start the bike in gear with the clutch out. My theory was if the signal from the gearbox was telling the bike that it was in neutral then it would try to start even when in gear. Well it didn't try and start so I think it must be a problem with the instrumentation because the bike will not attempt to crank unless it actually is in neutral.

Has anyone else had the problem of the neutral indicator being on all the time? Any ideas? Its still under warranty so if its nothing simple im hoping the dealers will sort it when I go back for the first service.

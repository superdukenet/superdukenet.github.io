The SD brake lever is the same as the Ducati 999, so you could try getting one of these, if not I have a spare brake lever you can use 'till you get one. It has a bit of oxidising under the laquer, which is why I changed them for the CRG anodised ones, but it works fine and would put you on for now. As for the power commander, you can't set it up yourself, you can buy one from Dynojet UK with a map already loaded, providing they have already set a SD up with the same exhaust you have. The best way by far, is to take the bike to a Dynojet approved centre, and let them set the bike up with a custom map for your bike. You can find a centre near you here;

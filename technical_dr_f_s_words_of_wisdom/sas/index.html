As I wrote in another thread too, removing SAS/SLS is not a 'just ripp it off' job like on a 950 with carbs. On the SD the system is connected to the ECU. This is the official info from KTM for the SAS removal kit:

"Mounting on 990 Superduke is only possible together with Akrapovic exhaustsystem 61005099000 including Akrapovic mapping!"

They don't say this for nothing. The mentioned part # is from the standard Akra slip-ons. So with other slip-ons you need to upload the Akra map for the slip-ons too and hope it works. With the right Akra mapping (KM610AK050E002) the ECU will say 'SAS/SLS not available'. Otherwise you'll get a flashing FI light as some have found out already...

With the full Akra system like I have, removing the SAS/SLS system isn't possible either. I have found out that this is possible but only with some additional mods to trick the ECU. But I don't know which. Yet...

The sad part is that IMO a decent dealer should tell this to their customers before they order the removal kit...

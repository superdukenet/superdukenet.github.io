Hi All,

I thought I would give some information on getting the tuneboy cable to work with Windows 10. I found it very difficult to get this up and running, so much so that I will probably change cables.

The issue is with the driver and the driver signature enforcement on Windows 10. When you plug the cable in and try find the driver using the device manager, you will likely get an error such as:
"Windows encountered a problem installing the driver software for your device.
Windows found driver software for your device but encoutered an error while attempting to install it.
The hash for the file is not present in the specified catalog file. The file is likely corrupt or the victim of tampering."

I got mine working by following the solution in the link below. Once I done this, I could install the driver(albeit twice as has been described in other posts).

https://www.howtogeek.com/167723/how-to ... d-drivers/

I hope this helps some people.

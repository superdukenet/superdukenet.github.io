#1
I recently installed a PC3 with O2 eliminators on an otherwise stock 08 SD. The bike had about 4700 miles on it prior to installation and never had any issues. After fitting the PC3 and O2 eliminators I've had the FI light come on twice in the last 1000 miles under cruising at about 60mph and ~50 degrees F. Both times the blink code (#17) pointed to a rear lambda sensor failure.

So two questions:

1) is this typical behavior for the O2 eliminators and I just need to ignore it
2) if it's not normal and I need to get a replacement from PC, which is the location for the rear sensor, the one under the tank or the one behind the battery.

If I have time I might try to swap the sensors and see if the code points to the front sensor. Thanks.

Dave

it's the one by the coolant reservoir... i had the same problem, apparently water can get into it easily. ( i had this problem 2x, once after rain, once after washing...) if it is not water, it might not be on all the way? not sure, it is very simple devise, just a resistor, so no likely it went bad... switching them around is a good idea, it should show you if one is bad.

it's not a big deal, you can safely operate the bike with the FI code 17, so no need to worry if it comes up and you're far away from home...

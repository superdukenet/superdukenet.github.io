Comrade: Here's a bit more info on the roll-over (tip over) sensor. I haven't got a photo of inside the shell but the photo of the bits were originally mine.

My memory is that if it is disconnected the bike runs but with the F1 light on. If it is there but a problem exists the bike won't run. The problem could be the bike over or the unit faulty and providing the wrong voltages. The tread lists the voltages and the page references.

Also you mentioned a "performance mod chip". That could be but typically these bikes get remapped using TuneECU which you can do yourself. It's probably done given all of the mods but it will probably be tuned for the Motohooligan and the Akro's.

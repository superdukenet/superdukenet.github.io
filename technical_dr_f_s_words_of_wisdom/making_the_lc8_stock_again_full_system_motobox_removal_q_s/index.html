#5
I wouldn't bother reinstalling the SAS, that is pointless. That is the only thing you would have put a resistor in for. Just tell the new owner its not installed. If they want to run standard cans and be kind to the environment then they can reinstall it.
If you want to put take the O2 sensor eliminators off with the PCIII then you can always just turn them off with TuneECU when you install the standard map. You'd be doing the new owner a favour leaving them disconnected. I think MrZ32 has a smoothed map for some standard bikes in the Map downloads thread. Take a look.

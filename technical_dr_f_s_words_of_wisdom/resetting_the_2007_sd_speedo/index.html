The reset the wheel size on the 2007 SD go to the Trip 2 screen and hold the mode button for at least 10 seconds and the 1879 length will appear. Hitting the mode button will increase the size by 1 mm and hitting the set button will descrease the size by 1 mm. When complete hit the mode AND the set button at the same time to return to the normal screen.

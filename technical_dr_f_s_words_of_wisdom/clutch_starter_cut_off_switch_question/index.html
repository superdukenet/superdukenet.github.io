This weekend I noticed that with the quickshifter fitted it sometimes stalls the engine when you're trying to snick up into neutral from first at traffic lights. That's expected....but what ( realised is that my starter won't work unless the bike is in neutral. I'm pretty sure that it used to be that if you pulled in the clutch then you could start the bike in any gear. There's a small micro switch with a long bit of spring steel underneath the left hand switch gear and the clutch lever has a rod which pushes this when the lever's in. I have ASV levers fitted but just can't remember whether this switch worked with the previous Rizoma levers fitted.

Has anyone got a photo of the set up to show me how the lever interfaces with the switch? Maybe I've fitted it incorrectly of the switch has been damaged in one of the Brands Hatch crashes last year. And aslo can someone confirm that the bike should start in any gear with the lever pulled in? If it doesn't then maybe I'm worried about nothing.

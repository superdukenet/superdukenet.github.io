This is the code for KTM orange (KTM/206). The pearlescent sparkle is mixed in the clear lacquer topcoat. Any good autopaint shop should be able to mix it, in Standox or similar make. Warning! it aint cheap!

This is the code to make 500g of paint :

Standohyd Basecoat(0)
WB379 ORANGE 284.0 284.0
WB380 GELB 184.9 468.9
WB370 WEISS 40.1 509.0
WB378 SONNENGELB 8.1 517.1
WB364 SCHWARZTONER 5.5 522.6


Standohyd Basecoat(1)
WB399 TRANSPARENT 496.8 496.8
WB343 NP => SATINGOLD 12.7 509.5


This is the same colour but different paint:

Basislack(0)
MB579 ORANGE 306.5 306.5
MB577 DUNKELGELB 127.3 433.7
MB570 WEISS 30.2 463.9
MB567 OXIDROT 12.7 476.5

Basislack(1)
MB599 STABILISATOR 449.5 449.5
PE843 NP => SATINGOLD 9.2 458.6

Sorry I was wrong, typed it in while in a hurry!

NOT the FL switch table but the 2nd flies table!!!

The 2nd flies table needs to have values in it, they are the % opening per throttle-rpm positions for the 2nd flies open. Similar to a fuel map.

If the values are in there and the box ticked the second flies should work.
You can put 100% in there all over, means they will open full all the time, kinda like you remove them.

Don't forget to re- upload the map!

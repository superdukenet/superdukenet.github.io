James has just sent me some smoothed out maps for standard SD/R. Here is what he wrote about them.

here are the standard maps that are now smoothened, this will make the newbs very happy.

The FL switchover can be applied to most maps with great results in smoothness but once a dyno tune map is created, you are going to have to be aware that the map was never designed to have these modifications applied.

You will notice that a lot of maps have a lean spot below 3k rpm because of the FL swichover and no matter how much tuning is done it wont accurately fix this because the ecu is reading two completely different maps under certain conditions. By changing the FL switchover, you are effectively causing the bike to only read off one map at any usable rpm (which your dyno tuner will thank you for later on) but will revert to the closed loop cycle at idle (to allow better running at idle).

My methodology was as follows:

1. Download the PCIII Software
2. Download a PCIII Map (M92-004) -Advanced Map*, Graves Slip ons , Stock air filter, Fuel table 1 is frt cyl
3. Copy the Table 1 and Table 2 trims to excel from the PCIII software
4. Using the Tables in the excal sheet, copy table 1 to table 2 and vice versa in the PCIII software.
5. Save the new PCIII map with the cylinder trim tables swapped.
3. Open the US Base .hex map in Tune ECU
4. Import the new PCIII Tables
5. Commit the Trims
6. Save Map (thank you Jambox)

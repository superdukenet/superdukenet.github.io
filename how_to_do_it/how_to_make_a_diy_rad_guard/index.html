How to make a DIY Rad guard

Post 1 by Superdan, 16 Jun 2009, 15:17

#1
Buy some mesh this one was good enough to make 3 rad guards:

http://cgi.ebay.co.uk/ws/eBayISAPI.dll? ... 0353576408

Then some edge trim:

http://www.woolies-trim.co.uk/c-330-pvc-edge-trims.aspx

Part no 304 Titanfast Edge Trim (I bought 4m)

Cut the ali using sharp scissors 342mm x 193mm.

Fit the trim round the edge and close using a vice to close the metal sill so it stays in place.

Using this measurement it does not need any tie grips just fits securely enough and as its a half moon it pushes back on itself securing it.

Can easily be painted black if needed and has no probs with rad temp.

Thanks to KTM worship on sourcing the sill.

Pics:






So have two spare £10 inc postage (superduke.net prices ) have put them both on my bike and fit very snugly. Believe all rad's are same size.

Got the SD dynoed at SPR http://www.sprracing.co.uk/power_commander.asp in Ruddington today - good set up and did a thorough job

Got 2 maps done - with and without baffles. Interesting thing that even with the correct map downloaded from the Power Commander site the bike was still running way too rich

Best result was a fraction under 117hp which I think is about right for an SD with Akra slip on's without baffles and a new BMC filter. Run with baffles in was only 2 ponies less. Would probually have got a bit more with a cooler engine.

Bike ran really smooth on the way home - bottom end fueling is fully sorted at last

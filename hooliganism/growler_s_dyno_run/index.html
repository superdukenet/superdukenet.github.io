In case anyone is interested in what a dyno run looks like with the same mods as me, here are the results of my dyno tune today.

Specifics:
2014 Super Duke 1290 with 2650 Miles
93 Octane Shell Premium Gas
Akra Map
Rottweiler SAS Stage 3 Removal Kit
Rottweiler Intake with Dual 80mm Stacks
Austin Racing Full GP-1 High Slung Exhaust
Temp: 68 Degrees F
Humidity: 45%
Pressure: 28.35 in-Hg
Correction Factor: SAE 1.04

Thanks to Rusty @ SM City Motorsports in Lexington Park, Maryland, for working time into his schedule to do this today!

The bike is almost ready to go.



Rusty was really surprised when we made the first run with a zero map. The Akra flash was almost spot on right from the start! He had never seen a "box" tune look this good.



Final Results
Rusty didn't have to make a lot of changes, but a few tweaks got me a few more Hp and a few more ft-lbs of torque!

1st run is with a zero map (Blue)
2nd run is from tuning just the front cylinder (Red)
3rd run is from tuning just the rear cylinder (Green)

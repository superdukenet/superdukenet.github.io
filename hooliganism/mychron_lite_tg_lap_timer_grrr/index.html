tg lights work VERY WELL when set up correctly. read the instructions, set your refresh rate. make sure to set the height of the beacon on a tripod at trackside to the same height of the signal reader on the bike. <<<(very important) the lazer it sends is a very narrow band to be broken.

i usually usually set the height with the bike next to the tripod in my pit stall to the correct height, before my first session. then i walk it over to the trackside.

set it up in a place on the track where the bike is straight up and down, not leaning over the slightest bit. start finish line is usually a good place.

dont turn the lap timer on until you go out for the first lap. if you do it in the pits to avoid forgeting to turning it on, and you dont hit the beacon within 5 minutes, it has an auto shut off feature. <<<(very important) and probably what happend to you.

make sure there are no other beacons on the track with the tg light specs, otherwise it is trying to read it multiple times. if someone else has a transmiter out there just use theirs.

lastly make sure you have good batteries in the beacon and the timer. i usually put my timer so i can read it as i ride. and look at it each lap so i know it is reading. possibly another reason yours didnt work.

good luck. ski

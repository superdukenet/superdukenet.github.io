reading the workshop manual it seems the ktm alarm is just a meta alarm with a different fob.

Meta instructions are here:

http://www.metasystem.co.uk/index.php/m ... /full/2420

If it is a meta, then on my last bike it worked like this:

If you leave it, 30 secs later it'll immobilise only on its own.

To set the alarm function you have to press the one button and it'll beep twice.

To disarm it press it again and it'll beep once.

The other button sets it off in a panic mode.

Does this sound right?

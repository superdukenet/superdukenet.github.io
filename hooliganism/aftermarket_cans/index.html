If you can't get it remapped anytime soon, don't worry about it too much, I ran mine for about a year (about 1.5/2k miles) with leo's on that the previous owner had fitted at some point (not sure how long he had them fitted for) and it seemed to run ok.

If you don't have a dyno/remapper nearby, but do have a KTM dealer/service place, they can install a rich map for aftermarket cans (called the Akra map). Or you can use TuneECU / PCIII/V and add someones custom map by yourself, if you feel confident enough.

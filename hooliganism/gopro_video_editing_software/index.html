For a very basic editing package with no fancy frills then download mpeg streamclip you can chop out the bits you want for uploading on youtube as simple as simple can be.

I was fortunate enough to have a mac and PC and so I have to give another thumbs up to imovie, a great package to be bundled in with the OS, I still use streamclip though, streamclip loads up a 20minute HD video in seconds whereas imovie takes forever so I open up streamclip to chop out the section I'm interested in and then save it and load it up into imovie to save time.

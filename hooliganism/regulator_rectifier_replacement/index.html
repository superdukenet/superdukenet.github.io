Hi Guys,

I've been having electrical issues so wanted to put the question out there as to if anyone has replaced the stock Voltage rectifier regulator with another brand. Some of the other forums are talking about replacing shunt style (like our standard KTM) to a mosfet one. They use different methods of getting rid of excess current etc and hence the mosfet ones run a lot cooler.

The model they are talking about is the Shindengen FH012AA used on Yamahas etc. I'll be looking at getting one of these soon with all the parts but just wondering if anyone has done the swap yet. As it seems the KTM is wired a bit differently.

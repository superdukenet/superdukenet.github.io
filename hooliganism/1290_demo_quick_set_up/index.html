Comrade: There is a little bit of vagueness about your definition of aggressive but given that you want TC I guess you'll also want ABS and it to be in road mode rather than in Super Moto mode. It's really the TC (MTC) that dumbs everything down and stops the thing being aggressive.

So really all you need to do is set the bike into "Sport" mode.

To do this:

Turn on the ignition. Favourites should appear on the multifunction screen.
On the multifunction switch press the down arrow once. Mode should appear.
Press the set button once.
Use the up/down arrows to highlight sport.
Press the set button. A message "Close the throttle will appear" and sports mode will be selected.
Press the return key to return to the favourites menu.
You are ready to go.

If you want full-on aggressive turn off both MTC and ABS then start to move and snap open the throttle. BE WARNED you've probably seen the video from Malaysia.
If you do want to turn off the MTC it's on the next menu down from drive mode but there is something a little quirky about selecting these options. From memory you have to press up/down, then set then return. The message is also "keep key pressed".

Oh BTW enjoy
